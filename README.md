# Kişisel Portfolyo Web Sitesi

Bu proje, bir Software Developer olarak yetkinliklerimi, projelerimi ve gelecek hedeflerimi sergilediğim kişisel web sayfamdır. GitHub Pages üzerinde barındırılmaktadır.

## 🔗 Canlı Ön İzleme
Siteye buradan ulaşabilirsiniz: [bariscoskunl.github.io](https://bariscoskunl.github.io)

## ✨ Öne Çıkan Özellikler
* **Çift Dil Desteği:** Türkçe ve İngilizce dilleri arasında hızlı geçiş.
* **Dinamik Arayüz:** Açılışta daktilo efekti (typing animation) ve etkileşimli menü geçişleri.
* **Modern Tasarım:** TokyoNight renk paleti, video arka plan ve cam (glassmorphism) efektleri ile modern bir görünüm.
* **Ön İzleme Kartları:** Sosyal medya bağlantılarında (LinkedIn, GitHub, Medium) üzerine gelince açılan profil kartları.
* **Responsive (Duyarlı) Yapı:** Mobil cihazlar ve masaüstü ekranlar için optimize edilmiş düzen.

## 🛠️ Kullanılan Teknolojiler
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
* **İkonlar:** Font Awesome
* **Barındırma:** GitHub Pages
